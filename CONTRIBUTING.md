# Contributing

Report data issues through GitHub with route, date, direction, official source URL, document version and page reference. Never publish booking references, passenger information or secrets. Operational issues belong with Steam Packet.

Follow UPDATE-TIMETABLE.md for imports. Withhold ambiguous dates until confirmed. New vessels or coverage require coordinated renderer, appendix and test updates. Run node validate-timetable.cjs, node build.cjs and node tests.cjs; verify both directions, gaps, overnight journeys, keyboard controls, mobile layout and offline use. Include evidence with a pull request.

Code contributions use MIT. Third-party content needs verified permissions and attribution. This compilation is not an official open-data release.
