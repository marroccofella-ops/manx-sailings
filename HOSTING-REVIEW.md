# GitHub Pages policy compliance statement

Reviewed: 17 October 2026. Scope: the current public manx-sailings repository and its static Pages research demonstration.

**Maintainer assessment: this site's present purpose and implementation conform to GitHub Pages' project-showcase use and avoid the prohibited online-business, e-commerce and commercial SaaS uses.** This is an evidence-backed project assessment, not a GitHub-issued approval, guarantee or legal certification. GitHub retains the final decision. An educational/AI label alone does not establish compliance.

## Purpose and prohibited uses

The site showcases open-source computational research: temporal coverage, schedule gaps, counterfactual removal, chronological baseline backtesting, local trained text classification and challenge evaluation, robust data-quality screening, historical weather analysis and synthetic tidal physics. Source, methods, tests, generated outputs and limitations are public.

It is not a reseller business, ticket storefront or paid software service. There is no checkout, fare sale, affiliate/referral tracking, commission collection, paid tier, payment handling, customer account or lead capture. Booking/status URLs in provenance are external references, not a commercial sales funnel. Any future commercial resale activity must use appropriate separate hosting and agreements; it is outside this Pages project's scope.

## Policy-to-evidence matrix

| GitHub requirement | Current implementation / evidence |
|---|---|
| Pages primarily showcases personal/organisational projects | README.md, research.js, environment.js, RESEARCH.md, MODEL-CARD.md, ENVIRONMENT.md and reproducible results |
| Do not use Pages to run an online business, e-commerce or commercial SaaS | Static demonstration; policy-tests.cjs checks for sales/tracking/password/payment UI indicators; no server-side transaction system |
| Main focus should not be advertising/promotional marketing | Research-first homepage and repo description; holiday hero and cross-brand promotion removed; no sponsorship inventory |
| Protect private and sensitive information | No account, cookies, analytics, passenger-data collection or private-email archive; tools run locally; publisher secret/path scans |
| Respect intellectual-property rights | LICENSE (MIT), LICENSES.md rights inventory, source citations, no operator PDFs/logos, separately attributed retained photograph |
| Respect Pages usage/build limits | Small static files and bounded local computation; pinned compressed weather source files; tests enforce a conservative 100 MiB site-budget cap (below the published 1 GB site limit) |
| Actions usage must relate to project production/testing/publication | CI only reproduces this repository's code, data exports and tests; historical network imports are manual, not scheduled |

Automated checks support this assessment but cannot establish legal compliance, data rights, traffic quotas or GitHub acceptance. Site transfer/build usage requires periodic review; this code does not claim access to account-wide bandwidth usage.
